# TP Teoria de Control - 2025 2C

Para ejecutar la simulacion, se debe clonar el repositorio o descargarlo en modo .zip. Una vez hecho eso, se debe abrir el archivo TDC.html con cualquier navegador y se le abrira la interfaz grafica para poder setear los valores de inicio y ejecutar la propia simulacion.

### Los valores a setear son:
    - Temperatura objetivo que desea tener en el horno
    - La temperatura ambiente que rodea al horno
    - Kp: Valor del controlador proporcional
    - Ki: Valor del controlador integral
    - Duracion deseada de la simulacion
    - Velocidad de la simulacion
    - Duracion de la perturbacion (abrir la puerta del horno)
    
### Se dispone de distintos botones para:
    - Iniciar la simulacion 
    - Pausar / Continuar la simulacion
    - Abortar la simulacion
    - Iniciar la perturbacion
